Accessibility to Parks & Green Spaces in Seoul

This project analyses the accessibility of green spaces in Seoul, using an isodistance map. For simplicity, it currently focuses on leisure parks (via Overpass API) as a proxy for green spaces, with plans to refine the definition. The isodistance analysis is powered by Geoapify API.
